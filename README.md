# InsightForge

Transform raw data into executive-grade insights using autonomous AI analysts team

## Vision

InsightForge is a multi-agent AI analytics platform where specialized AI agents collaborate to:

- Assess data quality
- Perform exploratory analysis
- Generate visualizations
- Extract business insights
- Critique Findings
- Produce Executive reports

## Architecture

Dataset Upload
    ↓
Data Quality Agent
    ↓
EDA Agent
    ↓
Visualization Agent
    ↓
Insight Agent
    ↓
Critic Agent
    ↓
Report Agent
